# Gate & Guard Projects - DESIGN.md

## 1. Purpose
Build a fast, trustworthy, premium local-services website for Gate & Guard Projects at `https://gateandguard.co.za`.

## 2. Brand decision
- Primary brand identity: **Gold + Silver shield** direction.
- Tagline: `Protect. Automate. Connect.`
- Service descriptor: `Security | Automation | Access | Solutions`

## 3. Visual direction
- Colors: Charcoal/Black (`#151a1e`, `#0b0e10`), Off-white (`#f5f4f0`), Gold (`#d99a1b`, `#e5aa32`), Silver (`#c9cdd2`).
- Clean, contemporary, flat UI with gold as accent.
- Typography: Barlow Condensed (Headings), Inter (Body/UI).

## 4. Contact/Quote Flow
- Client-side WhatsApp URL builder with phone and email fallbacks.
- Centralized data in `src/data/site.ts`.
